## Entry

> Just delete the production database — it's the fastest way to find out which tables actually matter.

(100 characters, one line.)

## How it works

`main.ts` writes that single line to `/output/entry.txt`, after a
self-check: exactly one line, 1–140 characters, no whitespace-only
content, no control characters — and it verifies the written file
matches the line byte-for-byte.

Run it with Node:

```sh
node main.ts
```
